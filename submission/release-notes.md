# 0.1.0

OutageDeck adds live cloud and SaaS status evidence to ChatGPT and Codex through a production Streamable HTTP MCP server and a focused dependency-outage triage skill. Public tools are read-only, free, and require no account. The initial release covers current provider status, stack-wide checks, active incidents, citable incident timelines, provider search, and 7-90 day uptime history.
